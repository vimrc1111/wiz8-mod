## 呼叫鏈與覆蓋證據

- 一般訊息框：0x0058ac00 在不能使用訊息佇列的分支，經 0x0058af2d → 0x005d2800 → 0x005d2887 → 0x005d2a50。後者輸出物件 +0x8c 的逐行陣列；0x005d2906 更新 +0x90 行數，既有析構路徑逐行釋放。
- 一般訊息／戰鬥訊息候選：0x0058aad0、0x0058ab60 格式化後分別經 0x0058ab50、0x0058abed → 0x0058ac00 → 0x0058ae76 → 0x0058af60。另有 0x005ada23、0x005adc6b、0x005ade15、0x005adf92 → 0x0058ac00。來源可分多次送出，這裡在加入各行之前處理，而非在單次畫字補救。哪些呼叫點對應實際戰鬥事件，尚缺 run 045348 的堆疊佐證。
- 對白文字候選：0x0052fa1a／0x00576142 → 0x005cf6c0 → 0x005cfb21、0x005cfb72 → 0x005d0050；同一提示框經 0x005cfedc → 0x005d0770 → 0x005d0590。高度與實際輸出必須一起改，否則會裁切下方文字。
- 對白輸入區：0x0058d9c0 → 0x0058dbf0 → 0x0058dca0；原版 0x0058dd27／0x0058dd89 用 0x00406f90 量指定長度，不只使用 0x00407010。保留文字本體、游標索引與捲動更新，沒有碰點擊關鍵字用的 0x0058fdd0。
- 說明／清單共用文字：0x005d16c0 → 0x005d1050 → 0x005d114d → 0x004f35b0；輸出經 0x005d1900 → 0x005d19ff → 0x005d1170。0x005df2c0、0x005df763、0x005dfe1f、0x005e000f 等說明清單建立點呼叫 0x005d16c0。物品與技能的具體畫面名稱仍需實機核對，不能只憑相鄰位址斷言兩者均已覆蓋。
- 一般文字物件：0x004f33a0 → 0x004f345d → 0x004f35b0，設定文字經 0x004f34d0 → 0x004f351b → 0x004f35b0；輸出 0x004f3710／0x004f39b0 按 LF 逐行畫字。因此新增 LF 必須擴充字串，不能覆蓋或丟掉中文字。

## 改寫邊界與相容性

- 由 144 個 0x00407010 呼叫點先找寬度比較與詞界，再追 0x00406ea0／0x00406f90 的指定長度量測。0x0040e71e／0x0040e752 是對齊；0x0058c988 是游標 x；0x00577410 是截短；0x005d5a10 是水平可視範圍，不算分行，不改。尚不能聲稱已窮盡間接呼叫與全部畫面。
- 原 0x0058ac00 的詞界為空格、TAB、LF、NUL，寬度達上限即回退；其餘找到的分行器以空格為詞界，富文字另有控制詞。未發現連字號斷點。純 ASCII 文字物件／彈出框／輸入區走原跳板；訊息與富文字局部改寫保留原 ASCII 分支、比較與空白處理。
- CJK 字元用同一個 0x00407010 量單字寬，涵蓋現有擴充字型。規則先判空白，再判 CJK 與避頭／避尾；不會拆 `%s` 或純拉丁詞。換行不加入可見空白、不刪除 CJK 字元。超窄框若連一個禁則組或完整拉丁詞都容不下，保留該組，仍可能溢框；無法同時滿足禁則與任意小框寬。
- 入口跳板長度：0x004f35b0 5、0x0058ac00 5、0x005d0050 6、0x005d0770 6、0x005d2a50 5、0x0058dca0 10。皆為完整指令且沒有相對分支；不複製棧探測的相對呼叫。每入口第一次呼叫記 `wrap hit` 加該入口位址。
- 局部續行用 pushfl／pushal 保存整組暫存器與旗標，C helper 只修改明列輸出，再還原堆疊續行；0x005d0d24 尤其需保留寬度比較旗標。富文字先安裝詞尾點，成功後才安裝掃描點。
- 文字物件與彈出框使用 proxy 既有的遊戲 MSVCRT 配置／釋放配對，不新增 CRT 匯入、第三方依賴或全域文字替換。配置失敗不釋放原文字；彈出框釋放已配置部分並回傳零行。
- 文字物件保留已有 LF。若在同一份已分行文字上改大框寬，已插入 LF 不會自動合併；需由原設定文字路徑重新供應來源。這是目前 CJK 重排的限制，ASCII 仍是原版。
