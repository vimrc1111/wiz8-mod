## 發現

- 命中貫通率原式為 `CTP = BaseAttackRatting + 5 * ToHit + 5 * Magical/Codition_ARmod + WeaponAttack_PEN_MOD + LOW_STAMINA_PENALTY + Combat_Modified_Monster_AC + floor(0.1 * (INT+DEX+SPD+SEN-INT-DEX-SPD-SEN))`，其中最後一項為攻擊方與防禦方四屬性差（程式碼解讀＋實測，peddroelm）[已驗證] https://steamcommunity.com/app/245450/discussions/0/2260187517790095687/
- `WeaponAttack_PEN_MOD` 原值：`Berserk -30`、`Lash -10`、`Bash, Punch -5`；彈藥另計（箭／弩矢 thrust 模式 `+10`，石彈 bash 模式 `-5`）[已驗證] https://steamcommunity.com/app/245450/discussions/0/2260187517790095687/
- `LOW_STAMINA_PENALTY` 原值：目前體力佔比 `>= 50%` 為 `0`、`< 5%` 為 `-40`（體力只影響貫通，不直接扣命中）[已驗證] https://steamcommunity.com/app/245450/discussions/0/2260187517790095687/
- `CTP` 只在 `CTH` 判定命中後才計算；未命中則不擲貫通（作者回覆確認）[已驗證] https://steamcommunity.com/app/245450/discussions/0/2260187517790095687/
- 難度直接乘命中率：新手 `x1.4`、普通 `x1.0`、專家 `x0.6`，在全部命中因子之後一次套用（專家近戰體感命中率崩跌的主因）[已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 基礎攻擊等級簡式為 `BAR = Round(12 + dex/30 + (2/45) * (CC_RC + 2 * WPN) + (ProfessionLvLUpMul * 2 * Lvl) / 30`，其中 `ProfessionLvLUpMul` 為戰士系 `4`、遊蕩系（Rogue／Bard／Gadgeteer）`3`、施法系 `2`；本體顯示值僅約真值的 `0.2`（CC_RC 以 `(21+24)/2` 近似，WPN 以 `[11 12 10 12]` 循環近似，偶差 `1` 點）[已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 命中加值來源原表：STR／DEX／SEN 依斷點給近戰與遠程 toHit（遠程取 STR 加值一半、副手再半、副手遠程僅四分之一）；`Power Strike` 近戰 toHit、`Eagle Eye` 遠程 toHit；`Bless` 不論 PL 皆 `+2`；`Enchanted Blade` 依 PL 為 `+1 +1 +2 +2 +3 +3 +4`；Rogue 背刺 `+10`（仍要先吃武器模式減值）；Fighter 招牌技 Berserk 另有隱藏 CTH 減值一說（見下條）[已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- Fighter 開 Berserk 承受隱藏命中減值、`Power Strike` 可部分彌補，此為指南作者「allegedly」用詞、未給原式，列為傳聞等級 [推測] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 玩家角色完整 `CTH` 原式未公開：指南 3.7 節只寫「AR defence range to target」，作者自承待補 Silicoid 資料，無全文 [未取得] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 每回攻擊次數原式（白負重、無雙持、無盾牌減值）為 `ATTACK_SPEED = Speed + Dexterity + 0.666666 * CloseOrRangedCombat + 1.333333 * WeaponSkill + LVL * 2 * ProfessionLvLUpMul`，`ProfessionLvLUpMul` 戰士系（含 Fighter／Lord／Valkyrie／Ranger／Samurai／Ninja／Monk）為 `4`（DEX 與 SPD 權重相等；STR 不直接參與）[已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 第三次攻擊對應 `ATTACK_SPEED >= 600`（由指南例題反推：`(600-(125+125+100*0.666666+125*1.333333))/8 => lvl 15` 戰士系滿技能；Ranger 弓／Fighter 例為 `lvl 17`、`lvl 19`），門檻常數原文未明寫，等號方向為反推 [推測] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 第二次攻擊的 `ATTACK_SPEED` 門檻常數在公開指南與 Biogoo 轉譯帖中皆無原文（只稱 1 級理論可達，實務靠升級），無原式 [未取得] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 每次攻擊揮擊數原式為 `Swing_Speed = SPEED + 10 * On_WeaponInitiative + 0.34 * CC/RC + 0.66 * WeaponSkill + LvL * ProfessionLvLUpMul`，`X >= 200` 得第 2 揮、`X >= 300` 得第 3 揮；實際揮數另有小幅 RNG（大幅超標可穩定打滿，武僧空手常打滿、Rogue 雙持常打不滿）；另有疑似 `3/3` 硬上限使慢速高傷武器後期反超 [已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 雙持攻擊／揮擊另式：主手 `X = X + (SkillMod + Dual weapons skill) * (1/3)` 配 `MHMod = -10 - (100 - Weapon skill) * (1/4)`，副手 `X = X + (SkillMod + Dual weapons skill) * (2/7)` 配 `OHMod = -20 - (100 - Weapon skill) * (1/4)`，其中 `SkillMod = (Combat skill + 2 * Weapon skill) * (2/3)`；雙持另砍 CC_RC／WPN 對 BAR 加成的百分比，高技能後期雙持反而降 BAR（Dual Weapons 僅線性補回每手至多 `+7`）[已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 回合先攻原式為 `Initiative = 11 + SPD_ini + SEN_init + Snake_Reflex_ini + Floor((Level - 1) / 2)`，SPD 與 SEN 皆為每 `5` 點 `+1` 先攻，`Snake Speed` 啟用 `+1` 後每 `10` 點再 `+1`；先攻採隱藏行動佇列，加速（Haste）追不上時保護法術施放者自身先攻必須最高 [已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 武器傷害原式為 `Round(RNG_Base * (1 + STRMod + OnWeaponDamage) * (1 + berserk + backstab + 1of(disabled,behind) + doubleVS) * (1 - targetDA))`，`RNG_Base` 為武器骰 `XdY+Z`（如匕首 `1d4+0`、雙刃斧 `2d8+5`）；`berserk` 為 `1／0`；0 體力者被近戰另有 `+100%` 加算（見體力條）[已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- STR 傷害傳遞比例原規則：主手近戰全額，多數遠程半額，副手半額，副手遠程（可雙持投擲）僅四分之一；滿 STR 主手近戰傷害可超過翻倍 [已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 技能即死率原式為 `CT_KillSkill = Floor(Floor((SKILL * 0.32) * 0.125))`（即 `SKILL * 0.04`），外加 `IF (RND(25) < (SKILL mod 25)) Then CT_KillSkill++`（例 `74` 點技能得 `2%` 保底＋`(74 mod 25)/25` 機率再 `+1%`）；滿 `125` 點為 `5%`，與武器／彈藥自帶 Kill% 疊加，每一揮獨立擲一次（揮數越多期望越高；Stiletto 自帶 `10%` 即為著例）[已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- Ranger 以 Ranged Combat 觸發遠程即死的機率原式未公開（指南只寫「so far unknown」），無原式 [未取得] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- Fighter 擊暈率可與石頭等裝備 KO% 疊加、抵抗看 Earth 系，此段指南語焉不詳且與怪物抗性制式不同，未見反組譯佐證 [推測] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393

- Monk 空手：`Martial Arts` 同武器技能參與 BAR／攻擊／揮擊三式並縮放空手基礎傷害，CC 每 `30` 點給空手武器先攻 `+1`，高階空手 `Swing_Speed` 可破 `500`（理論第 5 揮，但技能揮數上限卡 `3`）；Monk 另有減傷成長（ Damage Absorption 最高約 `+15`）；RPGCodex「12 attacks/round」與 `3` 攻擊上限矛盾，應為把揮擊併入計算的誇飾 [已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393

- Lord 專長為 HP 再生＋雙持（多被評為雞肋），Valkyrie 為 Polearm 專精＋「作弊死亡」：everything2 稱致命傷轉昏迷並回滿 HP，LP Archive 稱以 `1HP` 復活，兩說並存無公式；Samurai 另有 Fear 全免疫＋劍系 `25%` 加成（AtlusSeven 聚光燈） [推測] https://everything2.com/title/Wizardry+8

- 體力上限原式為 `MAX Stamina = Round((STR + VIT + PIE) * (0.7 + (level - 1) * 0.033))`；每揮消耗原式為 `CostStamina = weight * 0.025 + RND[weight * 0.025 + 1] + 2`（`weight` 為武器重量 `x10`，如 `1.5` 以 `15` 代入）；防禦回復原式為 `X = MaxStamina * 0.05 - 1`（`X < 1` 取 `1`，再 `X = X * K`，回 `2 * RND[X]`）；吟遊樂器耗體為 `BardNeedStamina = SpellLevel * 8 + 20` [已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 體力歸零即昏迷並 `RESETS BAC to -5`（一切 BAC 加成作廢），且攻擊者打 0 體力目標有 `+100%` 加算近戰傷害（敵我通用；低傷練技武器／吸體力詞綴可先抽乾再殺）；低體力另有輕微 BAC 減值與貫通減值（貫通 `<5%` 扣 `-40` 見前）[已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- HP 成長原式為 `Vitality point per Hitpoint Conversion = ((4 + 0.8 * Profession_HPmul) * (Level + 1)) / 200`，`Profession_HPmul` 原表為 Mage `1`、Psionic `2`、Bishop `3`、Alchemist `4`、Priest `5`、Gadgeteer `6`、Bard／Rogue `7`、Monk／Ninja／Ranger `8`、Samurai `9`、Lord／Valkyrie `10`、Fighter `13`（例 20 級 Fighter 百 VIT 約 `151.2` HP，同條件恰為 Alchemist 兩倍）；VIT 另為負重次要因子與體力三因子之一 [已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
- 任一主屬性基礎值 `100` 即解鎖專精技，對照原表為 STR→Power Strike、INT→Power Cast、PIE→Iron Will、VIT→Iron Skin（另有 DEX→Reflections、SPD→Snake Speed、SEN→Eagle Eye）；`28` 級配點應優先衝此線而非平均分配 [已驗證] https://gamefaqs.gamespot.com/pc/374906-wizardry-8/faqs/15137

- 技能成長原式為 `X = ((100 - SKILL) * ((Attr1 + Attr2) / 2)) * 0.01`，武器命中未傷得 `2` 次嘗試、命中兼傷害得 `4` 次、Berserk／背刺翻倍傷害得 `5` 次；法術成長為嘗試次數 `= 等級 * 施放 PL`（與成敗無關，紅圈練技最快）；長效增益另有現實 `3` 分鐘一跳規則（提早重放會重置計時，讀檔清零）[已驗證] https://steamcommunity.com/sharedfiles/filedetails/?id=899973393
